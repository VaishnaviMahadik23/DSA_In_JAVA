# Data Structures and Algorithms in Java

## 📖 Overview

This repository contains Java implementations of fundamental **Data Structures** and **Algorithms** commonly studied in computer science and used in technical interviews. The programs demonstrate efficient problem-solving techniques, tree structures, graph traversal, shortest path algorithms, minimum spanning trees, sorting algorithms, heaps, hash tables, and compression techniques.

The purpose of this repository is to provide easy-to-understand implementations for learning, practice, and academic reference.

- Tree Data Structures
- Graph Traversal Algorithms
- Shortest Path Algorithms
- Minimum Spanning Tree Algorithms
- Heap Data Structure

- Priority Queue Implementation
- Well-structured Java programs
- Beginner-friendly implementations

## 📂 Programs Included

| Program | Description |
|----------|-------------|
| **BinaryT.java** | Binary Tree implementation and traversal operations |
| **BSearchT.java** | Binary Search Tree (BST) implementation with insertion, searching, and traversal |
| **DFSGraph.java** | Depth First Search (DFS) Graph Traversal |
| **GraphBFS.java** | Breadth First Search (BFS) Graph Traversal |
| **Dijkstra.java** | Dijkstra's Shortest Path Algorithm |
| **PrimsG.java** | Prim's Minimum Spanning Tree Algorithm |
| **Kruskal.java** | Kruskal's Minimum Spanning Tree Algorithm |
| **HeapSort.java** | Heap Sort Algorithm |
| **MaxHeapSort.java** | Max Heap Sort Implementation |
| **MinHeapSort.java** | Min Heap Sort Implementation |
| **PriorityQ.java** | Priority Queue using Heap Data Structure |
| **Hashtable.java** | Hash Table using Linear Probing |
| **HTchaining.java** | Hash Table using Separate Chaining |
| **HuffmanIFU.java** | Huffman Tree and Huffman Coding Algorithm |

## ▶️ How to Run

### Clone the repository

```bash
git clone https://github.com/your-username/your-repository-name.git
```

### Navigate to the project

```bash
cd your-repository-name
```

### Compile a Java file

```bash
javac FileName.java
```

Example:

```bash
javac Dijkstra.java
```

### Run the program

```bash
java FileName
```

Example:

```bash
java Dijkstra
```
